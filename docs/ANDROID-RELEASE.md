# Mineradio Android 1.0.4 预览版

Android 7.0+，沿用原签名，可覆盖安装旧版。

- Folia 手机界面约 2.5 秒无操作后自动隐藏顶部切换栏、歌曲信息、播放控件和底部导航，让歌词、唱片或封面拼贴扩展到整个画面。
- 轻触画面唤回控制区；首次唤回不会误触暂停或切歌。拖动进度、音量或打开歌单、设置、更多菜单时保持可见，操作结束后重新计时。
- 保留 1.0.3 的单一原生 PCM 引擎，前后台连续播放与全部既有音效控制。

源码、手机浏览器与 Android 原生交互／状态验收已通过，公开 APK 已完整回下载核对版本、签名和校验值。完整功能取证使用同提交的 debug 包，签名 release 包另行验证安装及导入首页启动。云端模拟器未做扬声器听感验收。

显示验收边界：浏览器隐藏／恢复截图正常；云端 Android 的系统隐藏截图仍显示控件，与页面隐藏状态记录不一致，渲染或截图原因尚未确认，实际手机显示效果未验收。此前软件 GPU 也出现过图像合成异常。完整证据见 [发行与验收记录](https://github.com/oirge/Mineradio/blob/codex/android-mobile/docs/ANDROID-HANDOFF.md)。

格式支持与品牌省电策略取决于设备。Android 预览版与桌面 Latest 独立发布。
