# Mineradio Android 1.0.4 预览版

Android 7.0+，沿用原签名，可覆盖安装旧版。

- Folia 手机界面约 2.5 秒无操作后自动隐藏顶部切换栏、歌曲信息、播放控件和底部导航，让歌词、唱片或封面拼贴扩展到整个画面。
- 轻触画面唤回控制区；首次唤回不会误触暂停或切歌。拖动进度、音量或打开歌单、设置、更多菜单时保持可见，操作结束后重新计时。
- 保留 1.0.3 的单一原生 PCM 引擎，前后台连续播放与全部既有音效控制。

源码、手机浏览器与 Android 原生验收通过后发布。完整功能取证使用同提交的 debug 包，签名 release 包另行验证安装及导入首页启动。云端模拟器未做扬声器听感验收；部分软件 GPU 截图仍有既有图像合成异常。

格式支持与品牌省电策略取决于设备。Android 预览版与桌面 Latest 独立发布。
