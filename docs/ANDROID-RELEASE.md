# Mineradio Android 1.0.3 预览版

Android 7.0+，可覆盖安装旧版，沿用原签名。

- 手机端所有音乐统一由常驻原生 PCM 引擎播放；前后台切换只同步界面，不再更换音频引擎或重新加载当前歌曲。
- 前台、锁屏和移除最近任务后均保留10段EQ、自动/手动预增益、限幅、立体声宽度、ReplayGain及防削波、倍速、无缝接续与交叉淡入淡出。
- 普通舞台和Folia共享真实原生频谱、播放进度和内嵌歌词；通知栏支持暂停、继续、切歌和跳转。
- 平台解码并使用有界PCM缓冲；倍速保留音高。原生限幅保留所有设置，但其压缩算法与WebAudio不保证逐样本相同。

安装包只有在源码回归、手机浏览器和Android原生验收全部成功后才发布。云端Android验收包含同一AudioTrack连续性、真实PCM音效、倍速、交叉混音、歌词与重启恢复；模拟器没有音频监听，未将帧计数检查描述为真人听感测试。

此为预览版，品牌设备和特殊编码格式仍取决于Android平台支持。桌面版本和Latest更新入口保持独立。
