# Mineradio Android 1.0.5 预览版

Android 7.0+，沿用原签名，可覆盖安装旧版。

- Folia 手机控制区隐藏和唤回改为柔和淡入淡出，缩短滑动距离；歌词与舞台位置平滑移动，唤回时保持背景完整。
- 保留约 2.5 秒无操作后自动隐藏。首次轻触只唤回；拖动进度、音量或打开菜单时保持可见，操作结束后重新计时。
- 保留单一原生 PCM 引擎、前后台连续播放与全部既有音效控制。

Node 1692 项、手机浏览器 11 项、Android 原生 14 项和 DSP 原语 8 项通过。公开 APK 已完整回下载，版本、原签名、SHA256SUMS、GitHub digest 和同一云端 run 的签名构建包一致。

截图核对：最终浏览器截图：隐藏图中顶部导航、歌曲信息、播放控件和底部导航均已消失，歌词舞台铺满视口；恢复图中四组控件正常显示，舞台回到原布局；最终 Android 系统截图：原始系统隐藏截图仍显示四组控件及原舞台布局，与同轮 DOM 隐藏和满舞台记录不一致；恢复截图四组控件正常显示。渲染或截图原因未确认，实际手机显示效果未验收。完整结果与独立 CI 结论见 [发行与验收记录](https://github.com/oirge/Mineradio/blob/codex/android-mobile/docs/ANDROID-HANDOFF.md)。

完整功能取证使用同提交 debug 包，签名 release 包另验安装及导入首页启动；云端模拟器未做扬声器听感验收。实际手机显示效果与品牌省电策略仍需更多设备覆盖。Android 预览版与桌面 Latest 独立发布。
