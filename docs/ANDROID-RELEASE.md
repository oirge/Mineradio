# Mineradio Android 1.0.1 预览版

下载 `Mineradio-Android-1.0.1.apk` 安装，支持 Android 7.0 及以上。

## 1.0.1 修复

- 修复 Android 读取音乐文件标签时字节偏移失效，导致内嵌歌词无法识别、Folia 没有歌词的问题。
- 元数据分块读取支持较大的歌词和封面标签，避免原生单次读取上限截断。
- 旧版缓存的识别失败结果会重新扫描，保持歌曲身份和原有收藏、歌单关联。
- 沿用 1.0.0 签名，安装版本号提升，可覆盖安装更新。

## 手机功能

- Mineradio 与 Folia 两套手机界面，可在播放期间切换。
- Folia 歌词、悬浮唱片、封面拼贴，以及曲库、视觉效果、播放设置与音频工具适配手机触控和横竖屏。
- 使用系统文件选择器导入手机音乐或文件夹，保存访问授权，重启后恢复曲库。
- 应用内置界面资源，本地音乐播放无需电脑；包含媒体通知和后台播放服务。

云端验证包含浏览器 320–1024 像素横竖屏检查、APK 签名校验，以及 Android 模拟器安装、文件导入、播放、后台运行和重启恢复。

此版本为 Android 预览版，尚未覆盖所有品牌手机及系统省电策略。音频格式支持由系统 WebView 决定；依赖桌面服务的在线翻译、桌面视频导出等功能暂不支持。

`SHA256SUMS.txt` 提供安装包校验值。此预览版独立发布，不改变桌面应用更新版本。
