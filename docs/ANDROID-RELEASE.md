# Mineradio Android 1.0.2 预览版

下载 `Mineradio-Android-1.0.2.apk` 安装，可直接覆盖安装 1.0.0／1.0.1，支持 Android 7.0 及以上。

## 后台播放

- 切换应用、回到桌面或锁屏时，由前台媒体服务中的原生播放器接管音乐。
- 移除最近任务后继续播放，并独立完成队列续播。
- 通知栏、锁屏媒体按钮支持暂停、继续、上一首、下一首和进度控制。
- 返回 Mineradio 或 Folia 时，同步当前歌曲、播放位置和暂停状态，避免两套引擎同时出声。
- 处理音频焦点、耳机断开、播放唤醒锁及服务生命周期；系统设置中的“强行停止”仍会结束播放。

保留 1.0.1 的内嵌歌词读取修复及旧缓存重新识别，原有歌曲身份和歌单关联保持。

## 范围

前台继续使用 WebAudio，可视化与音效设置恢复原样；原生后台暂不执行 WebAudio 音效、ReplayGain 和交叉淡入淡出。后台解码格式取决于 Android 系统播放器。

Android 预览版尚未覆盖所有品牌手机和省电策略。系统若限制后台运行，可在应用的电池设置中允许后台活动。此版本独立发布，不改变桌面应用更新版本。

`SHA256SUMS.txt` 提供安装包校验值。
